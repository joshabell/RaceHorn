# Oil Rig Cookies™ — Website Prototype

A **satirical / parody** product landing page for a fictional peanut butter
cookie brand, "Oil Rig Cookies," positioned as a tongue-in-cheek counter to the
equally fictional "woke windmill cookies."

> ⚠️ This is a joke. The product is not real. No real political movement,
> company, windmill, or peanut is endorsed or disparaged. The "pre-order" form
> is a prop and does not collect, store, or transmit any data.

## What's here

| File | Purpose |
|------|---------|
| `index.html` | The single-page landing site (hero, mission, flavor specs, comparison, testimonials, FAQ, fake pre-order form). |
| `styles.css` | All styling — oil-rig/Americana aesthetic with a peanut-butter palette. |
| `script.js` | Lightweight, self-contained form handler. Sends nothing anywhere. |

## Run it

It's a static site with no build step or dependencies. Open `index.html`
directly in a browser, or serve the folder:

```bash
cd oil-rig-cookies
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Theme

- **Flavor:** peanut butter
- **Aesthetic:** oil derrick + Americana, amber/crude palette
- **Tone:** clearly-labeled parody (a satire banner sits at the very top)
